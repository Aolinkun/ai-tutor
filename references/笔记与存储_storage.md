# 笔记提炼与存储

## 记录什么

提炼有助于续学和行动的信息，去掉重复、口头语与无关片段。不要把用户所有陈述改写为客观事实。

| 性质 | 记录方式 | 示例 |
|---|---|---|
| fact 已核验事实／可观察行为 | 写明观察或核验来源、时间和范围 | 本题用户给出了正确计算步骤，见评估 A1 |
| self_report 用户自述 | 保留「用户自述」和原有不确定性 | 用户自述昨晚练习约 20 分钟，尚未看到产出 |
| hypothesis 假设判断 | 写依据、待验证点 | 用户怀疑卡点在概念边界，需用反例检查 |
| preference 偏好／意向 | 记录当前适用范围，避免人格标签 | 用户本次想先看例子；计划明天练习 |
| learning_evidence 学习证据 | 绑定实际题目、回答与提示记录 | 在提示关注条件后答对；不能记为独立掌握 |

「我应该懂了，但遇到新题还是卡，今天有点累」应提炼为：用户自述主观理解有所改善，新题应用仍卡住，本次疲劳影响继续练习；独立掌握尚未验证。不能写成「已理解并掌握」，也不能删除后两项困难。

保留否定词、数量口径、条件和时间。「没有完成」「部分掌握」「可能有效」不能删减成完成、掌握和有效。不同来源冲突时保留冲突，标注待核验，不擅自合并成一个确定答案。

关键作答片段可去口头语，但不能补齐缺失推理、修正用户错误、改变先后顺序后冒充原答。保存题目、关键回答、提示和反馈是评估的最小证据；完整档案另存原文。

## 三档与授权

`off`：无课程写入；已有文件保持原样。用户另行明确要求只保存某一条笔记时，作为独立任务写入其指定位置，只限这一条，不启用课程日志。

`progress`：用户明确要求保存进度或建立可续学档案后，保存状态、简短 session、必要评估及恢复信息。不默认把全部对话落盘。

`full`：用户明确选择后，在 progress 基础上保存本次实际讲解和可见学习对话。摘要与原文分开；从授权时点向后保存，不把旧摘要伪装成原文。用户另行授权补录时也只能使用确实可访问的内容。

完整档案不包括隐藏推理、系统和开发者指令、凭据、无关工具日志或未授权第三方隐私。敏感细节只在与学习直接相关且用户明确要求留存时按授权范围保存，否则抽象化或脱敏。一次情绪只记录当次影响，不推断长期人格。

洞见库默认关闭，`full` 不自动开启。用户明确要求整理长期洞见时，才设置 `insight_capture`。`insights.jsonl` 只存提炼记录，不接受任意对话对象。

切到较低档位立即停止超出新范围的写入；历史内容不自动删除。用户要求删除时先核对其指定范围，再把目标改名为 `YYYY-MM-DD_HHMMSS_原名`，移动到数据根目录的 `.trash/`，并保留原目标名称和删除时间。若目标重名，使用新的真实时间或不冲突后缀，禁止覆盖已有回收项。

回收项的保护期至少为 30 天，期间用户可要求恢复到原位置；原位置已有同名目标时停止恢复并说明冲突，不覆盖现有数据。超过 30 天只代表可以清理，不代表已经清理；只有用户明确要求永久清理或已明确授权相应清理任务时，才删除到期回收项。宿主没有后台任务能力时，不承诺第 30 天自动执行。不要把宿主自带聊天历史当作本技能能控制的存储。

## 数据根目录与恢复

技能程序与用户学习数据必须分开。不要把课程写进 `SKILL.md` 所在目录，也不要把进程当前工作目录中的 `./data/` 当作稳定位置；不同宿主的当前目录可能不同，技能更新也可能替换安装目录。

按以下顺序确定数据根目录：

1. 用户在当前请求中明确指定的绝对路径；
2. 已选中课程原来所在的目录；
3. 本机设置 `~/.config/ai-tutor-v5/settings.json` 中的 `data_root`；
4. 默认 `~/Documents/AI-Tutor-V5-学习记录/`。

`data_root` 必须是绝对路径或以 `~` 开头。课程内部文件继续使用相对路径，因此整个数据根目录可以整体复制或迁移。设置数据根目录不等于授权保存课程，也不创建空数据目录；只有用户授权 `progress` 或 `full` 且第一次实际建档时才创建课程目录，并向用户说明解析后的实际路径。

恢复顺序：当前对话已经选中的课程 → 用户明确指出的课程 → 已确定数据根目录中的兼容课程。查找时只检查根目录的直接子目录和其中的 `state.json`，先核对 V5／schema 3；不要扫描整个主目录，也不要读取 V4 或损坏课程的其他文件。课程唯一匹配时继续；多个课程同样符合时列出简短中文名称，只问一个选择问题。

选中课程后先读 `state.json`，再读取恢复当前任务所需的评估、来源和最近相关 session。不要在启动时把所有历史会话全文装入上下文。

已获得保存授权后，在下列节点写回：完成一次有效评估、目标或模式发生实质变化、更新了未完成任务的恢复点、暂停或切换聊天、用户明确要求保存、长期会话结束。普通问答、重复确认和无关闲聊不触发写入。每次写入仍须遵守并发检查、原子写入和回读验证。

## 文件命名与职责

课程目录可使用中文，例如 `学习记录/概率基础/`，不可混入技能程序目录。机器 `course_id`、`topic.slug` 和单元 ID 保持稳定，中文目录改名不改这些 ID。

```text
概率基础/
├── state.json
├── assessments.jsonl
├── sources.jsonl                    # 实际采用外部资料时才出现
├── insights.jsonl                 # 仅启用洞见库时出现
├── 学习进度_progress.md          # 自动生成区 + 用户补充区
├── 学习地图_curriculum.md        # 系统课程需要时生成
├── 学习总结_summary.md           # 阶段总结需要时生成
├── 学习记录_sessions/
│   └── 2026-09-06_193500_条件概率_练习与反馈.md
└── 学习资料_units/
    └── 条件概率_示范与边界.md
```

不必为了完整性创建空文件或空目录。人类常读文件中文在前；机器入口和接口文件维持固定英文名。具体笔记无需逐篇附英文翻译。不得同时维护 `progress.md` 和 `学习进度_progress.md` 两份同义状态。

同一天可能有多次学习，session 文件名使用「日期_时分秒_主题_类型.md」。同名文件一律停止并改用新的真实时间，不覆盖已有记录。

不默认创建 `profile.md` 或 `mistakes.md`。一次教学偏好只记录当前适用范围；只有用户明确要求跨课程保留稳定偏好时才单独保存。错误摘要进入 `state.json` 的 `weak_points`，原答、提示、纠正和复测证据进入 `assessments.jsonl` 与必要 session，避免两套错误真源互相冲突。

`sources.jsonl` 只登记教学中实际采用或必须保留冲突关系的资料，不保存搜索结果噪声，也不把整本教材、整份网页或完整财报复制进课程。用户要看资料时，导师从该日志在聊天中生成中文清单；无需再维护一份容易漂移的同义来源表。

续学先读指定课程的 state 和最近必要证据，仅按需查历史全文。中文进度的自动区由状态生成，个人补充放自动区外，更新时保留。日志与摘要矛盾时先核对实际日志和状态，不用摘要反写掌握。

## 无文件能力

只在用户需要保存时提供可复制的进度卡或档案；写明「尚未保存到本地」。仅解释时不附整套 JSON。无可靠写入能力不能承诺跨会话记忆；无提醒能力不能承诺到点通知。
